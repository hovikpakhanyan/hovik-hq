# Command core

The signed-in command surface is the center stage, between Agents and Chat on a wide screen. Its label remains COMMAND / READY.

The drawing is original canvas artwork: rotating arcs, radial spokes, a flowing waveform, and orbiting points. It is not a Marvel asset. On a phone the field is small enough that six stable shortcuts sit around it. Those shortcuts open the existing Agents, Chat, Listings, Pipeline, Tasks, and Markets views. They do not move.

The microphone control is off until tapped. It uses this browser only, shows amplitude, and releases the mic when the page hides, the session ends, or Stop is pressed. Nothing is recorded or uploaded. There is no Grok Bot voice connection. `prefers-reduced-motion` paints one still frame.

Desktop wide layout keeps the side columns and the bottom modules. The phone layout removes the bottom band that was clipped by the browser chrome.
